## Text Policy

- Prefer little to no explanatory prose inside the plotted image. Keep labels and numeric annotations compact, then explain the interpretation in the surrounding thesis text, LaTeX caption, or this review/index file.
- Text-heavy semantic material, such as candidate taxonomy, should become a LaTeX table in the thesis body when possible; keep the PNG mainly for review, slides, or quick visual reference.

## Main Defense Flow

Use this compact sequence for slides or paper figures:

1. `paper_dataset_regime_map.png` - dataset regimes and scale context.
2. `architecture_pipeline.md` - previewable Mermaid architecture source for Mermaid or TikZ reconstruction.
3. `candidate_taxonomy.png` or a LaTeX table equivalent - label semantics for EDGRec candidates, paper-faithful baselines, and sampled ablations.
4. `results/optuna_figures/optuna_crru_selection_frontier_by_dataset.png` - validation search selection only.
5. `paper_claim_matrix.png` - full-data test comparison against LightGCN paper-faithful rows.
6. `paper_accuracy_efficiency_frontier.png` - full-range accuracy/runtime frontier over completed test rows.
7. `paper_accuracy_efficiency_frontier_zoomed.png` - zoomed companion for the non-outlier cluster.
8. `paper_mechanism_diagnostics.png` - score mix and branch diagnostics, not causal proof.
9. `paper_baseline_feasibility.png` - resource-probe feasibility with both ratios and seconds/epoch.

## Backup Figures

- Dataset profile figures are useful appendix/backup material. They are too dense for the main narrative but good for committee questions about splits, density, feedback type, tails, and side features.
- Optuna heatmaps and response plots are validation-search diagnostics. They should not be presented as final test evidence.
- `accuracy_popularity_tradeoff.png`, `accuracy_popularity_tradeoff_zoomed.png`, and `crru_component_decomposition.png` are supporting backup figures. They are useful for committee questions but should not all appear in the main defense flow.
- `kuairec_matrix_regime_sensitivity.png` is a targeted appendix/backup figure for explaining why small-matrix KuaiRec rows are not the sparse comparison.

## Misleading Claims Avoided

- No defense figure uses internal candidate-elevation wording.
- EDGRec-family rows are not split visually by thesis/supporting provenance; a completed test row is a comparison candidate.
- The EDGRec reference row is the highest-CRRU completed EDGRec-family test row from `results/query_results.md` semantics. It may be a thesis profile, supporting row, or ablation row.
- Sampled LightGCN and DICE-style rows are labeled as non-paper ablations, not paper-faithful baselines.
- Runtime-probe rows are resource evidence only; one-epoch accuracy from probes is diagnostic.
- Speedup figures show raw seconds/epoch as well as ratios.
- Missing LightGCN paper-faithful comparators, if any appear in future data, are labeled as probe-only or no full-data row.
- Branch score-mix, cosine, Spearman, and branch-rank panels are mechanism diagnostics, not causal effect identification.
- CRRU is a thesis utility score, not a causal estimator, fairness metric, or universal cross-dataset score.

## Result Caveats To State Verbally

- AmazonBook: current EDGRec-family reference is an efficiency alternative, not an accuracy or popularity-concentration win against LightGCN paper-faithful.
- KuaiRec v2: strongest current positive EDGRec-family evidence uses the sparse watch-ratio comparison row; near-ceiling small-matrix/full-observation rows are sensitivity evidence, not the default thesis comparator.
- MovieLens-1M: near-parity accuracy with speed benefit; LightGCN paper-faithful still has slightly higher NDCG/Recall and lower VRAM/AvgPop.
- KuaiRand-1K: compact randomized-exposure stress-test evidence; do not present it as a standard-view ranking win.
- DICE paper rows are runtime probes only until full accuracy rows exist.
- Multi-seed robustness remains an evidence gap for headline claims.
